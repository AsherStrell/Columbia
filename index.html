      Identification Guide

      Has Singing

      Monophony (Greek)
      Kyrie
      Listen for the first word "Kyrie"
      Monophony (Latin)
      Introit / Alleluia
      Listen for the first word "Alleluia" — this one is in monophony
      Polyphony (Latin)
      Leoninus' Alleluia / Perotinus' Viderunt Omnes
      Listen for "Alleluia" — this one is in polyphony (multiple voices)
      Polyphony (Latin + English)
      Byrd / Dowland
      Byrd = imitative polyphony, no instruments, angelic. Dowland = lute song with voice. If in English with orchestra, it's Handel.
      Solo Voice + Continuo (Italian)
      Monteverdi
      Solo singer with harpsichord/organ continuo. Between singing and speaking. Small ensemble, not full orchestra.
      Orchestra (English)
      Handel
      Byrd has no instruments. Dowland might include lute or harpsichord. If in English and there is orchestra, it is Handel.
      Orchestra (Italian)
      Mozart
      Full orchestra, dynamics shifting, voices shaking. Don Giovanni.
      Voice + Piano (German)
      Schubert
      German art songs (Lieder). Only instrument is piano but there IS singing. Dramatic and emotional.

      No Singing

      Solo Harpsichord
      Bach
      Sounds piano-like but plucking. Fugue — instruments chasing each other. Constant energy.
      Full Orchestra / Symphony
      Beethoven
      Famous da-da-da-daaa (Mvt 1). Dramatic shifts between movements.
      Violin with Orchestra
      Mendelssohn
      Crying violin opening. Very sad. Violin-specific concerto.
      Only Piano
      Chopin
      Waltz. Goes really fast at times. Very major key and happy.
      Horn-centric Orchestra
      Berlioz
      Not songs you would hum to. Creepy (Mvt 5 = slasher film vibes). Program music.
      Clarinet with Strings
      Brahms
      Chamber music. Clarinet quintet.
